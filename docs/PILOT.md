# Tavryn pilot plan

## Three steps

1. Run one Nigerian buyer's supplier programme (a Lagos manufacturer or FMCG company with
   20 to 50 SME suppliers) in parallel with its current process, using one lender and a
   small set of approved invoices.
2. Onboard the buyer's suppliers through the buyer's approval portal; import approved
   invoices from the buyer's ERP/accounting export.
3. Add a second lender, ideally one bank and one fintech or microfinance lender. Measure the funding-time improvement and demonstrate the
   privacy/single-financing rejection that makes shared governance valuable.

## Required integrations

- Buyer ERP/accounting export or API for invoice import and approval status.
- Financier credit/origination system for funding decisions and limits.
- Naira settlement through the lender's own bank, recorded on the ledger by payment
  reference (the existing off-ledger path); Canton Coin or a stablecoin only where the
  participants and their regulators allow it.
- Optional: registering the financed receivable in the National Collateral Registry, so
  the lender's claim is also on the public notice record.
- Identity/onboarding controls for supplier, buyer, financier, auditor, and governance
  operators.

## Pilot metrics

The pilot will measure approval-to-funding time, rejection latency, financing success
rate, duplicate approval attempts, and operational exceptions. No metric is populated
until observed.
